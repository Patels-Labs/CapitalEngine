1. Definitions

"CapitalEngine" means the software in this repository, including the
CapitalEngine core plugin, the CapitalEngine API, and the add-on plugins
published with it.

"The API" means the Java classes and interfaces in the package
com.patelheet.capitalengine.api and its subpackages, as published by the
copyright holders. That includes the artifact com.patelheet:capitalengine-api
and the copies of those classes inside CapitalEngine.jar.

"An Add-on" means a work that uses CapitalEngine only through the API: by
compiling against the API, calling it, implementing interfaces the API
documents as meant for plugins to implement, or listening to its events.
An Add-on contains no other part of CapitalEngine's source code or object
code, in modified or unmodified form, other than unmodified copies of the API
that the Add-on's build tools need in order to compile it.

above.

You need not, and should not, bundle the API inside your Add-on, because
CapitalEngine provides it at runtime. If you do convey unmodified copies of
the API with your Add-on, those copies remain under the GPL with this
exception, and you must say so and say where the corresponding source can be
obtained.

This permission does not extend to modified versions of the API or of any
other part of CapitalEngine. Those remain under the GPL.
