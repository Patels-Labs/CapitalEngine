# Security policy

An economy plugin's worst bugs are the quiet ones: a way to duplicate coins or items, to create money from nothing, to move someone else's money, or to read the owner dashboard without logging in.

**Please report these privately**, not in a public issue: use GitHub's [private vulnerability reporting](../../security/advisories/new) on this repository. Include the plugin and version, the steps to reproduce, and what you expected to happen.

We'll reply within a week, fix confirmed problems in a patch release, and credit you in the release notes unless you'd rather we didn't.

Only the latest release of each plugin gets security fixes.
